# 📦 ProdManager

Sistema web para gerenciamento de produtos, desenvolvido como projeto acadêmico com o objetivo de aplicar conceitos de desenvolvimento full-stack e persistência de dados.

## 📌 Sobre o projeto

O **ProdManager** é uma aplicação web que permite gerenciar produtos por meio de operações de cadastro, consulta, edição e exclusão.

O projeto foi desenvolvido com o objetivo de colocar em prática conceitos de desenvolvimento **frontend e backend**, além da integração com um **banco de dados relacional**.

## 🎯 Objetivos

- Desenvolver uma aplicação web para gerenciamento de produtos;
- Implementar operações de cadastro, consulta, edição e exclusão;
- Integrar frontend e backend;
- Trabalhar com persistência de dados;
- Aplicar conceitos de desenvolvimento full-stack.

## ✨ Funcionalidades

- ➕ Cadastro de produtos;
- 🔎 Visualização de produtos;
- ✏️ Edição de produtos;
- 🗑️ Exclusão de produtos;
- 💾 Persistência dos dados em banco de dados relacional.

## 🛠️ Tecnologias utilizadas

- JavaScript
- HTML
- CSS
- Node.js
- Banco de dados relacional
- npm
